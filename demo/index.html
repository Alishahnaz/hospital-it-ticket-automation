About the implementation

The PAD action list runs locally in Power Automate Desktop. This interactive preview demonstrates the same routing conditions but has its own CSV parser and exporter for browser-based exploration. The browser can handle quoted commas; the original PAD sample writes CSV by concatenating values and has a narrower input format.
